项目背景

项目需要同时支持 VR 玩家端、PC 裁判端和转播观战端。基础系统不只是登录 / 设置，还要处理账号权限、跨设备登录、顶号、网络异常、多语言、系统设置与未来赛事扩展。

我的职责

三端权限设计

拆分 Player、GM、Spectator 的可用能力与操作边界。

文档与沟通

输出系统文档，和程序、UI、测试同步边界与规则。

设计思路

Framework

将 Player、GM、Spectator、Guest 等身份抽象为 Role，区分账号类型、客户端类型与权限能力，避免把规则写死在单个客户端。

Configuration

将设置项按 bool / int / char 等参数类型与控件类型拆分，让程序可读取、策划可维护、后续功能可扩展。

Scalability

通过统一配置、统一状态与统一异常处理，把未来赛事、房间和观战扩展预留在底层框架里。

设计亮点

把复杂流程拆成可配置规则。

把异常情况前置成状态表。

用 Role 管理权限，而不是写死客户端。

让设置系统同时适配 VR 射线交互与 PC 鼠标交互。
