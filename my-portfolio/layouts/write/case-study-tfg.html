项目概览

基于 VR 跆拳道动作的节奏玩法模式。玩家根据节奏与视觉提示，用规定身体部位击打 Note 或躲避 Block。

系统通过 Timing、命中部位、方向偏移、Combo、生命值等规则形成评分与失败判定。

我的职责

  • 系统玩法设计
  • 核心规则设计
  • 判定与得分规则设计
  • 玩家反馈设计
  • 文档撰写与跨岗位沟通

设计目标

为非专业玩家和跆拳道运动员提供局外训练 / 娱乐玩法。

用关卡机制降低学习门槛，让动作目标更直观。

为后续 UGC 谱面编辑器与异步 PVP 提供基础规则。

核心玩法循环

音乐开始 Note / Block 生成 玩家完成动作 命中与 Timing 判定 Combo / 分数 / 生命值反馈 结算评级

系统拆解

Note

承载击打目标、身体部位、方向与 Timing 信息。

Block

要求玩家躲避或调整身体位置，打破单纯击打节奏。

Chart

组织谱面节奏、目标类型、生成时机与关卡难度。

音轨运动

定义目标移动轨迹、抵达节奏点和玩家预判时间。

判定系统

检查命中部位、方向偏移、Timing 窗口与动作完成度。

得分系统

将命中质量转化为分数、Combo、评级与即时反馈。

生命值系统

把失误转化为压力反馈，形成失败条件和节奏张力。

关键设计亮点

  • VR 身体部位判定
  • 方向 Note 的击入 / 击出点设计
  • Timing 判定窗口
  • Note 与 Block 的场地 / 音轨逻辑
  • 兼顾休闲玩家与技术流玩家
