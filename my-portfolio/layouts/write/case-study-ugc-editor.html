为 VR 节奏跆拳道项目设计的 UGC 谱面编辑器，覆盖谱库管理、音乐导入、BPM 分析、2D/3D 编辑、实时试玩和谱面导出等完整流程。

谱库管理 BPM 分析 Timeline 2D / 3D 编辑 实时试玩 配置表

项目背景

节奏跆拳道需要稳定的谱面生产工具，让策划和玩家能把音乐节拍转化为可试玩、可验证、可导出的 Note / Block 数据。

设计目标不是做一个普通列表工具，而是把音乐分析、谱面编辑、场景预览、试玩校验和导出流程合成一条低门槛工作流。

负责内容

  • 编辑器整体流程设计
  • UI 线框与页面状态设计
  • Song / Difficulty / Timeline / Note 数据结构规划
  • 基础配置与难度系数配表设计
  • 和程序、美术沟通编辑器交互与落地边界

核心工作流

导入歌曲 自动分析 BPM 创建曲目 创建难度 2D / 3D 编辑 实时试玩 导出谱面

设计亮点

音乐分析

导入歌曲后自动识别 BPM，并生成节拍网格，减少手动对拍成本。

编辑器先建立音乐结构，再进入谱面编辑，保证后续 Note 放置有稳定时间基准。

二维 / 三维同步编辑

2D 时间轴负责精确定位，3D 视图负责空间关系和玩家动作可读性。

双视图同步能让编辑者同时检查节奏、轨迹、距离和身体部位目标。

时间轴编辑

通过曲目列表和时间轴入口管理谱面版本，降低多首歌、多难度切换成本。

波形预览与节拍定位服务编辑效率，让谱面修改不依赖反复进出关卡。

网格吸附

目标位置基于节拍和空间网格吸附，减少拖拽误差。

它让 UGC 编辑更接近“配置节奏与动作目标”，而不是反复微调坐标。

实时试玩验证

编辑过程中提供试玩入口，快速验证 Note 密度、动作可行性和节奏压力。

试玩结果反向指导编辑，形成“编辑 → 验证 → 修正”的短循环。

配置表设计

把基础配置和难度系数拆开，让同一首歌可以生成不同难度版本。

参数计算遵循“基础配置 × 难度系数”，便于平衡节奏密度、速度和容错。

数据结构设计

谱面数据按 Song → Difficulty → Timeline → Note 分层，清晰区分曲目信息、难度版本、时间轴和具体目标。

这种结构利于导入导出、版本管理和后续异步 PVP / UGC 内容扩展。
